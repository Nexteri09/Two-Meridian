# Text and Code Formatting Rules

## 1. No Long Hyphens
Never use em-dashes (long hyphens) or en-dashes in code, markup, documentation, content copy, or chat suggestions.
- Use simple standard hyphens (-), colons (:), periods (.), or commas (,) instead.
- Incorrect: "6 unusual nations — hover to locate"
- Correct: "6 unusual nations. Hover to locate"

## 2. No Emojis
Never use emojis anywhere in the codebase, markup, UI text, documentation, or chat responses.
- Keep all visual indicators strictly typographic, cartographic, or SVG-based.
